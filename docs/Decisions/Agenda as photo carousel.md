# Agenda as photo carousel

## Context
Each event should show a picture and details, like the main event panel.

## Decision
Agenda rows became photo cards with details on black glass, in a category-filtered snap carousel (one carousel, not one per category).

## Consequences
With few events, one row per category would be sparse; a single filtered carousel stays full.
